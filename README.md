# Bluestock Mutual Fund Analytics Capstone

## Overview

This project analyzes mutual fund performance, NAV trends, SIP inflows, investor transactions, and fund house AUM using Python, Pandas, SQLite, and SQL.

## Project Structure

* data/raw - Original datasets
* data/processed - Cleaned datasets
* scripts - Python ETL and cleaning scripts
* sql - Database schema and analytical SQL queries
* reports - Documentation and data dictionary

## Technologies Used

* Python
* Pandas
* NumPy
* SQLite
* SQLAlchemy
* Git & GitHub

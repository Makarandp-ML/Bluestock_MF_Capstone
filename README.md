# Bluestock Mutual Fund Analytics Capstone

## Project Overview

This project analyzes the Indian Mutual Fund industry using data engineering, exploratory data analysis, performance analytics, advanced risk metrics, and business intelligence dashboards.

## Objectives

* Build an ETL pipeline
* Create a SQLite analytical database
* Perform exploratory data analysis
* Calculate fund performance metrics
* Build interactive Power BI dashboards
* Develop advanced analytics and risk models
* Generate business insights and recommendations
